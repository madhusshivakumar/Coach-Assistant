# scripts/

One-off CLI utilities. Phase-0 placeholders:

- `fetch_statsbomb.py` — mirror the StatsBomb open-data repo at a pinned commit.
- `fetch_pff.py` — download the PFF FC 2022 World Cup release.
- `regen_fixtures.py` — reproduce trimmed fixtures under `tests/fixtures/`.

Anything used more than twice gets promoted into `src/football_analysis/data/cli.py`.
